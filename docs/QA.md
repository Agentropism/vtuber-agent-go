# 当前仍然存在的问题

- vup建模，建模完全僵死，录入动作数据，让ai识别数据然后识别最优保存到资料库里可以
- ui界面需要重定向
- QQ的职责需要更加的明确，直播时怎么安排QQ的消息
- 链路连接不稳定：agent服务端（Open-LLM-VTuber）重启后，网关和bilibili-live无法自动重新连接，需要各组件在项目重启时具备自动重连能力
- B站事件类型识别不全：SC（Super Chat）、点赞等事件无法正确反序列化
- 回复语义TTS重叠：多句回复的音频片段播放顺序错乱/重叠，需要对TTS输出做排序，确保按句子顺序依次播放
- TTS语速不自然：当前合成语速单一，需要调整语速参数或更换更自然的TTS模型
- 表情映射不准确：LLM输出的表情标签没有正确的对应，不应该将表情表情当作字符展示
- Live2D反馈很差：模型动作单一、口型不同步、表情过渡不流畅，整体表现力不足
- 缺少自动找话题能力：直播间无弹幕时VUP沉默，需要加入空闲时自动发起话题的机制
